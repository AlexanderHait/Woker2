# Виджет: кнопки в мессенджеры и форма заявки

Встраиваемый виджет одним файлом (`widget.js`, чистый JS, без сборки и зависимостей)
и маленький сервер с выдуманными данными, чтобы виджету было у кого спросить настройки
и куда отправить заявку.

## Запуск

```
python3 server.py
```

Нужен только Python 3.8 или новее, ставить ничего не надо. Команда поднимает сервер
на `http://127.0.0.1:8080` и открывает демо-страницу. Если порт занят, берётся следующий
свободный; отключить автооткрытие браузера — `--no-open`. Чтобы открыть демо с телефона
в той же сети — `python3 server.py --host 0.0.0.0`, адрес сервер напечатает сам.

## Подключение на чужом сайте

Владелец сайта вставляет две строки и больше ничего не делает:

```html
<script async src="https://cdn.example.com/widget.js"></script>
<div data-cw-source="landing-tg" data-cw-counter="12345678"></div>
```

| Атрибут | Зачем |
|---|---|
| `data-cw-source` | идентификатор источника, по нему сервер отдаёт кнопки и шаги формы |
| `data-cw-counter` | номер счётчика Метрики для этой страницы; если счётчика на странице нет, виджет ставит его сам |
| `data-cw-api` | адрес API, если он не на том же домене, что и сам скрипт |
| `data-cw-debug` | писать ошибки в консоль; без него виджет молчит |

Что показывать — кнопки, форму или и то и другое — решает ответ сервера, а не разметка.

## Состав

```
widget.js           виджет целиком
server.py           демо-сервер: настройки, приём кликов и заявок
selftest.py         тесты серверной части (python3 selftest.py)
data/sources.json   выдуманные настройки трёх источников
data/leads.jsonl    принятые заявки (создаётся при первой заявке)
data/clicks.jsonl   зафиксированные нажатия
demo/index.html     демо: три блока, переключатели отказов, журнал сервера
demo/hostile.html   чужие агрессивные стили и двойное подключение скрипта
demo/blocked.html   страница, где аналитика заблокирована политикой безопасности
```

API сервера: `GET /api/config?source=…`, `POST /api/lead`, `POST /api/click`.
Служебные, только для демо: `GET /api/_mode?target=config|lead&mode=ok|fail|slow|empty`
и `GET /api/_state` — журнал последних кликов и заявок.

## Где проверять сценарии из задания

| № | Сценарий | Где смотреть |
|---|---|---|
| 1 | Обычное подключение | демо-страница, блок 1 |
| 2 | Заход по рекламной ссылке | кнопка «Открыть с метками», дальше правый клик по кнопке → копировать адрес |
| 3 | Одно нажатие — одна цель | журнал «Клики» внизу демо-страницы; вызовы самой Метрики видны в режиме `?ymlog=1` |
| 4 | Медленный уход со страницы | блок 2, кнопка «Открыть Telegram в приложении» (уходит в текущей вкладке) |
| 5 | Аналитика заблокирована | `demo/blocked.html` |
| 6 | Сервер списка кнопок лежит | «Сломать (500)», «Замедлить», «Пустой список» + перезагрузка |
| 7 | Скрипт подключён дважды | `demo/hostile.html` |
| 8 | Два блока с разными настройками | демо-страница, блоки 1–3 |
| 9 | Агрессивные чужие стили | `demo/hostile.html` |
| 10 | Телефон, узкий экран | режим телефона в DevTools |
| 11 | Прогресс после перезагрузки | заполнить два шага формы в блоке 1 и обновить страницу |
| 12 | Отправка без сети | Network → Offline, отправить форму; потом вернуть сеть |
| 13 | Двойное нажатие «Отправить» | журнал «Заявки»: запись одна |
| 14 | Кривой формат телефона | ввести `8 (912) 345-67-89`, в журнале будет `+79123456789` |
| 15 | Проход только с клавиатуры | Tab, стрелки, пробел, Enter |

Решения по спорным местам — в `NOTES.md`.
